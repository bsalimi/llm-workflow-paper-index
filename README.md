# Protected paper index

This repository hosts an encrypted literature index on GitHub Pages. A shared password is required to decrypt the index in your browser.

The password is not stored in this repository. Saved summaries, annotations, paper records, and citations are included in the encrypted page and open after unlocking, without a GitHub login. Empty imported summary templates are labeled explicitly.

PDFs are linked separately through public paper sources and Google Drive. Drive copies retain their existing access permissions.
